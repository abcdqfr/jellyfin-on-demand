# Swarmplay 0.3.0 (batch episode fanout)

Commemorative tier: pick an episode inside a multi-file TV / season-pack
release, then warm and play that file. Also fixes search-history first-click
and finishes the MKV head gate so Attachments/fonts are warm before play.

## Highlights

- **In-release episode picker:** TV play calls `POST /Swarmplay/swarm/list-files`,
  lists video files, and lets you choose which index to `play-bind`. Movies
  skip the picker.
- **`FileIndexExplicit`:** the chosen index is not overwritten by auto-pick.
- **`FileIndexPicker` hardening:** ports strmarr BatchFileIndex lessons
  (absolute cour numbers like “3rd Season 49,” NCOP/NCED skip, dense-band
  normalize) ([ADR-008](../adr/008-batch-episode-fanout-v0.3.md)).
- **History first-click:** capture `focusin` / `pointerdown` on
  `#searchTextInput` so the dropdown appears on the first click.
- **Head Attachments gate:** `parse_head` requires complete Attachments (or
  Cluster) so ASS fonts are on disk before ready.
- **Library promote** commemorative target moved to **0.4**.
