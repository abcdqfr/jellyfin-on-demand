# Jellyfin on Demand 0.1.5 (hotfix)

## Odyssey “invalid torrent identity”
Not a bad magnet. Jellyfin could not create `/tmp/jellyfin-on-demand/<btih>/` when that
tree was owned by the interactive lab user. Deploy now `chmod 1777` the cache
and reclaims dirs for `jellyfin`. Native mkdir failures are `io_error` (-5), not
`-2`.
