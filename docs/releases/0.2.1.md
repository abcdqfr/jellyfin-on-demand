# Jellyfin on Demand 0.2.1 (MKV-aware extent gate)

Hotfix tier: replaces the blind fixed 8 MiB tail + 8 MiB head warm floor with
a growing, structurally-verified native MKV/EBML probe, porting forensics
from strmarr's Tensura cold-gate incident
([ADR-007](../adr/007-mkv-aware-extent-gate.md)).

## Highlights
- Native: `torrent/native/src/mkv_probe.{h,cpp}` — minimal EBML reader,
  `parse_head` (Segment → Tracks/Attachments only) and `find_cues`
  (backward multi-candidate Cues scan, false-positive-safe)
- `session_stub.cpp`: `tail_mib`/`head_mib` are now floors; head grows
  1 MiB → parsed size (floor 8 MiB); tail grows 2 MiB → 16 MiB cap hunting a
  real Cues element, bounded cue-less fallback if none parses; probe result
  cached per (torrent, file_index), never re-parsed once warm
- No ABI break: `swarm_ensure(source, file_index, tail_mib, head_mib, out)`
  keeps its signature; non-MKV files keep the prior fixed-floor behavior
- Gate: new `mkv_probe_test` native unit-test target (no libtorrent, no
  gtest) covering a valid head parse, a truncated/retryable head, the
  Tensura-shape "Cues past a naive tail window" miss, a false-positive
  Cues-ID match that must be skipped, and a cue-less file
