# Swarmplay 0.1.0 (integration)

Local integration cut. Client: **Jellyfin Desktop** against a Jellyfin 10.11
host that loads this plugin. No strmarr / *arr / Seerr services.

## Artifact

```sh
./scripts/package_release.sh 0.1.0
# → dist/swarmplay-0.1.0/
#     Jellyfin.Plugin.Swarmplay/   (DLL + meta.json)
#     libswarmplay_native.so
#     README-INSTALL.txt
```

## Install (host)

1. Build/package as above (needs `.tools/dotnet`, libtorrent, existing native build).
2. Copy `Jellyfin.Plugin.Swarmplay/` into the host plugins dir  
   (e.g. `/var/lib/jellyfin/plugins/` or user datadir `…/plugins/`).
3. Ensure the Jellyfin process can load the native library:
   `LD_LIBRARY_PATH=/path/to/dist/swarmplay-0.1.0:$LD_LIBRARY_PATH`
   (or install `.so` on the system library path).
4. Restart Jellyfin. Confirm plugin loads (logs: Swarmplay / Jellyfin Enhanced 0.1.0.0).
5. Point **Jellyfin Desktop** at that server. Smoke:  
   `POST /Swarmplay/swarm/play-bind` with a magnet (see `scripts/jf_ensure_local_smoke.py`)  
   or paste magnet path once UI is wired.
