# Jellyfin on Demand 0.1.0 (integration)

Local integration cut. Client: **Jellyfin Desktop** against a Jellyfin 10.11
host that loads this plugin. No strmarr / *arr / Seerr services.

## Lab host (this machine)

```sh
make up          # package → deploy plugin+native → start system jellyfin → verify
make status
make smoke       # needs JF_USER=… JF_PASS=…
```

Jellyfin Desktop → `http://127.0.0.1:8096` (or this host’s LAN IP).

## Artifact

```sh
./scripts/package_release.sh 0.1.0
# → dist/jellyfin-on-demand-0.1.0/
#     Jellyfin.Plugin.JellyfinOnDemand/   (DLL + meta.json)
#     libjellyfin_on_demand_native.so
#     README-INSTALL.txt
```

## Install (host)

1. Build/package as above (needs `.tools/dotnet`, libtorrent, existing native build).
2. Copy `Jellyfin.Plugin.JellyfinOnDemand/` into the host plugins dir  
   (e.g. `/var/lib/jellyfin/plugins/` or user datadir `…/plugins/`).
3. Ensure the Jellyfin process can load the native library:
   `LD_LIBRARY_PATH=/path/to/dist/jellyfin-on-demand-0.1.0:$LD_LIBRARY_PATH`
   (or install `.so` on the system library path).
4. Restart Jellyfin. Confirm plugin loads (logs: Jellyfin on Demand / Jellyfin Enhanced 0.1.0.0).
5. Point **Jellyfin Desktop** at that server. Smoke:  
   `POST /JellyfinOnDemand/swarm/play-bind` with a magnet (see `scripts/jf_ensure_local_smoke.py`)  
   or paste magnet path once UI is wired.
