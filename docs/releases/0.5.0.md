# Jellyfin on Demand 0.5.0 — Discover pane

Minor feature release: a Seerr-shaped **Discover** browse home inside the
Jellyfin Enhanced chrome, next to Enhanced Panel / Bookmarks.

## Highlights

- **Discover sidebar pane** — Trending, Popular Movies, Movie Genres,
  Upcoming Movies, Popular Series, Series Genres, Upcoming Series (Seerr
  default order; arr/Plex-only sliders omitted).
- **Same Play / Lucky / Library** as search — reuses rolled-in
  `js/jellyseerr/*` card chrome (JE Seerr client, retargeted; no Seerr
  process).
- **TMDB-backed** discover APIs when Jellyfin on Demand discovery is on and Seerr is
  off (`/JellyfinOnDemand/jellyseerr/discover/*`).
- **Search landing link** — empty search page offers “Browse Discover”.
- **Attribution** — [`ATTRIBUTION.md`](../../ATTRIBUTION.md) documents JE
  jellyseerr chrome rolled into this fork (GPL-3.0) plus MIT seerr Discover
  pattern takes (genre tones / slider titles).

## Fixes bundled

- Discover no longer navigates to Jellyfin’s `#/discover` 404 route.
- Empty Discover pane from a bad class selector (`.sections.jellyfin-on-demand-discover`).
