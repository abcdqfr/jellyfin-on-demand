# Jellyfin on Demand 0.1.8 (hotfix)

## Real Jellyfin player
play-bind now mints a library `Movie` Guid pointing at the growing file, returns
`ItemId`, and the client issues `Sessions/{id}/Playing?playCommand=PlayNow` to
Jellyfin Desktop. That is the same player chrome + ffmpeg path as library Play —
not a plugin `<video>` overlay.

## Libtorrent metadata pivot
Torznab magnets keep tracker `tr=` (sanitized ASCII; `dn=` dropped). Native session
bootstraps DHT, drains alerts, unlocks during metadata wait, and caches metainfo under
`$JELLYFIN_ON_DEMAND_CACHE_DIR/metainfo/<btih>.torrent`. Status exposes peers/trackers/`has_metadata`
so unreachable pins fail loud instead of a mysterious player toast.
