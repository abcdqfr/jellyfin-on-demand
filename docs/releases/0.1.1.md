# Swarmplay 0.1.1 (hotfix)

## Why
Living-room search faceplanted after re-enabling Seerr-style poster chrome:
persisted/default `JellyseerrShowSearchResults=false` blocked init, and the
fixture path had been removed. Admin TMDB Test still hit the old route prefix.

## Fix
- Public-config forces search results on when `SwarmplayDiscoveryEnabled`
- Client init ignores legacy ShowSearchResults when Swarmplay discovery is on
- Gate catches stale `/JellyfinEnhanced/` admin API URLs and this discovery gate

## Install
```bash
make up          # package 0.1.1 → deploy → verify
# tag: v0.1.1
```

Hard-refresh Jellyfin Desktop. Re-Test/Save TMDB key if validate previously 404'd.
