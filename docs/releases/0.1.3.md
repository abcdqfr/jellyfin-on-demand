# Jellyfin on Demand 0.1.3 (hotfix)

## `native_error_-2` in English
**Invalid torrent identity** — libtorrent rejected the infohash/magnet (code `-2` =
`SWARM_ERROR_INVALID_ARGUMENT`). Common causes: ANSI-corrupted magnet strings,
empty source, or a bad hash. Try another release from the picker.
