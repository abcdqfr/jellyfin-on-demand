# Jellyfin on Demand 0.5.1 (hotfix / RC: Discover playback yield + hide search link)

Hotfix on top of 0.5.0 (Discover pane). Release-candidate polish: Discover
must leave the page stack before Jellyfin’s player/details show, and the
broken Search→Discover landing link is hidden.

## Highlights

- **Discover yields to player / item details** — hide before warm/play; do not
  restore the previous JF page on top of video; DOM/hash safety net.
- **Stronger auto-play** — try `playbackManager.play({ items })` and auto-click
  JF’s detail Play button so the extra “press Play” step is avoided when possible.
- **Search landing “Browse Discover” link disabled** — use sidebar Discover.
